# Week 1 Notes: Data Preparation for Machine Learning

My own notes from the Databricks Academy course *Data Preparation for Machine Learning* (v4.0.0).

## Modules

| # | Module | Lessons |
|---|--------|---------|
| 1 | Managing and Exploring Data | Load data from Unity Catalog volumes, profile and explore it |

- Requires **serverless environment version 6** (`_common.py` checks for it); the notebooks are pinned to v6.
- Datasets: `databricks_telco_customer_dataset` and `databricks_diabetes_health_indicators_dataset`
  (same Marketplace shares as weeks 2 and 3).
